    Rapport — symboles — 2026-09-26

    Session sur les quatre cours à la fois : le sujet remplace le code de cours dans le nom du rapport (SPEC-INGESTION, étape 6).

    Demande

    Sur fpp/duration, l'utilisateur ne comprenait pas $P(t,r)$ : « je pensais que les deux paramètres devaient être des dates ». Puis : « oui fais-le, et d'ailleurs ça devrait être une règle pour tous les cours, la rubrique "Ce que les symboles modélisent" quand c'est nécessaire. Ajoute-en dans les cours où ce n'est pas encore fait, puis push. »

    Vérifié dans le poly : la Déf. 5 écrit bien $P(t,r)$, maturité et taux, là où la Déf. 3 écrit $P(t,T)$, deux dates. C'est une collision interne à la source ; la fiche était fidèle, il lui manquait l'explication.

    Mesure

    Avant la session, la rubrique n'était due que si le registre attribuait un symbole à la fiche. 53 fiches portaient une Forme sans elle : 29 dans dup, 11 dans fpp, 3 dans pfo, 10 dans dss. Après : aucune.
