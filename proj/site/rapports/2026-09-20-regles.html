    Rapport d'ingestion — les règles établies passent dans les documents — 2026-09-20

    Huitième session du jour. **Aucune fiche, aucun inventaire, aucun registre, aucun script touché.** Objet : inscrire dans les quatre documents les décisions prises au fil des sept sessions précédentes, qui ne vivaient jusqu'ici que dans les rapports et dans le code.

    Le nom du rapport suit la convention que cette session vient elle-même d'écrire : une session sans cours prend le sujet à la place du code.

    Matériau traité

    CLAUDE.md, SPEC-MODELE.md, SPEC-INGESTION.md, SPEC-SITE.md — dans leurs deux copies, racine et proj/, vérifiées identiques avant et après.

    Pourquoi cette session

    Sept sessions ont produit des décisions qui gouvernent le dépôt : comment créer un principe, comment référencer un cours à plusieurs sources, ce qu'on attend d'un exemple minimal. Elles étaient justes et déclarées, mais rangées dans des rapports — c'est-à-dire dans un journal, pas dans une loi. Un opérateur qui reprend le dépôt dans deux mois lit les quatre documents, pas huit rapports. Ce qui n'y est pas écrit n'existe pas.
