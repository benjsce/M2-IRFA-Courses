## Énoncé
You need the ridge solutions for a decreasing grid $\lambda_1>\lambda_2>\dots>\lambda_T$. In which order do you solve them, and why?

## Solution officielle
Start from the largest $\lambda$: $X^\top X+\lambda I$ is then dominated by $\lambda I$, hence well conditioned and easy to solve, and a crude $x^0$ (say $0$) is already good enough. Then decrease $\lambda$, each solution warm-starting the next: consecutive problems differ little, so each solve takes few iterations. Going the other way, the first problem solved is the hardest one and you have nothing to start it from. Unlike the Lasso, ridge has no finite $\lambda$ for which $\hat{w}=0$.

## Résolution
Two effects push the same way. Conditioning: $\kappa=(\sigma_{\max}^2+\lambda)/(\sigma_{\min}^2+\lambda)$ decreases to $1$ as $\lambda$ grows, so the first solve is cheap. Distance: at large $\lambda$, $\hat{w}\approx X^\top y/\lambda$ is small, so $0$ is a close start; afterwards, the previous solution is closer than $0$ to the next one.

On the four observations: at $\lambda=100$, $\kappa\approx1.02$ and $\hat{w}\approx(0.0095,\,0.0195)$, within $0.02$ of $0$. From $\lambda=1$ to $\lambda=2$, the warm start $(\tfrac1{11},\tfrac7{11})$ is $0.16$ from the new solution $(\tfrac2{19},\tfrac9{19})$, against $0.49$ for $0$ — about three times closer in the $A$-norm too.

- ods/regularization-path: the order is dictated both by the conditioning and by the availability of a good start; each argument alone would already suffice.
