## Ce que c'est
Deux flux identiques dans tous les états du monde ont le même prix aujourd’hui. [§3.1, §2.4]

## Ce qui la définit
Une différence de prix entre deux flux identiques serait encaissable sans risque ni mise : c’est ce qu’on interdit. [§3.1, §2.4]

## Cesse d'être valide quand
Rien, dans le périmètre du cours. En marché incomplet elle cesse de suffire à déterminer un prix unique. [ajout]

## Origine
- exercice fpp/ex-05 : l'arbitrage ne se lit pas « le forward est cher », mais « le forward et le comptant impliquent deux dividendes différents » [exo. 5]
- exercice fpp/ex-12 : trois strikes donnent trois valeurs de $C-P+K$ ; deux suffisent à construire l'arbitrage sans jamais connaître le comptant [exo. 12]
- exercice fpp/ex-17 : contre-exemple utile — « toute la hausse, pas de baisse » ressemble à un arbitrage ; ce qui le disqualifie n'est pas dans le payoff mais dans les dividendes abandonnés [exo. 17]
