## Énoncé
Écrire un script Python qui : 1. simule, avec une graine fixe, 60 mois de rendements du portefeuille de marché et d'un actif ; 2. calcule leurs rendements au-delà d'un taux sans risque fixe ; 3. estime par `statsmodels` une régression par moindres carrés, en ajoutant explicitement une constante ; 4. affiche les coefficients estimés et la p-valeur de $\alpha$.

## Solution officielle
Graine 42 ; marché $\mathcal N(0{,}006\,;0{,}04)$ par mois, 60 tirages ; $R_f=0{,}1\,\%$ par mois ; actif $=R_f+1{,}3\,(R_m-R_f)+0{,}0016+$ un bruit $\mathcal N(0\,;0{,}02)$. Puis `X = sm.add_constant(exces_marche)`, `modele = sm.OLS(exces_actif, X).fit()`, et l'affichage de `params[1]`, `params[0]` et `pvalues[0]`. [p. 73, p. 74]

## Résolution
Le script officiel a été rejoué tel quel (numpy 1.26, statsmodels) : [ajout]

| coefficient | vrai | estimé | erreur type | t | p-valeur |
|---|---|---|---|---|---|
| $\alpha$, par mois | 0,16 % | 0,157 % | 0,245 % | 0,64 | 0,52 |
| $\beta$ | 1,3 | 1,339 | 0,068 | 19,7 | $2\times10^{-27}$ |

$R^2=0{,}870$. Sans la constante, la pente vaut 1,337 : l'écart est faible ici parce que le rendement moyen du marché au-delà du taux sans risque est petit devant les fluctuations. [ajout]

**Lecture.** Le bêta est retrouvé à 3 % près et très significatif. L'alpha est retrouvé presque exactement, 0,157 % pour 0,16 %, et pourtant on ne peut pas rejeter qu'il soit nul : sa p-valeur est de 0,52. Avec un bruit de 2 % par mois, soixante mois donnent à l'alpha une erreur type de 0,245 %, plus grande que l'alpha lui-même. Il faudrait environ $(2\times0{,}245/0{,}16)^2\times60\approx560$ mois, près de 47 ans, pour que $t$ atteigne 2. [ajout]

## Ce que l'exercice a révélé
- pfo/alpha-de-jensen : un vrai alpha de 1,9 % par an est invisible sur cinq ans de données mensuelles.
- pfo/statistique-t : une statistique faible ne prouve pas l'absence d'effet ; elle mesure ce que l'échantillon permet de voir.
- pfo/regression-du-medaf : `add_constant` est indispensable ; sans lui, la constante est forcée à zéro.
